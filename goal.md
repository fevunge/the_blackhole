## Interview Preparation

### Technical Interview Framework

```
1. Clarify — faz perguntas antes de escrever código
2. Examples — cria 2-3 exemplos concretos (incluindo edge cases)
3. Approach — explica o plano antes de implementar
4. Code — implementa com narração em voz alta
5. Test — passa pelos exemplos manualmente
6. Optimize — discute complexidade e alternativas
```

### System Design Framework

```
1. Clarify requirements (functional + non-functional)
2. Capacity estimation (users, data, requests/second)
3. High-level design (componentes principais)
4. Deep dive (o componente mais crítico/interessante)
5. Trade-offs & alternatives (o que ficou de fora e porquê)
6. Failure scenarios (o que acontece quando X falha)
```

### Questions to Ask the Interviewer

- O que define sucesso nesta função nos primeiros 90 dias?
- Como é o processo de code review e deployment?
- Qual é o maior desafio técnico que a equipa enfrenta agora?
- Como gerem a dívida técnica?
- Qual é a stack e como chegaram a ela?

# 🔥 MOTIVATION & MINDSET

## A Verdade Sobre Este Roadmap

**Este roadmap é hardcore.** Não é para toda a gente. É intensivo por design.

Se num dia não consegues fazer as 4-6 horas, faz 1 hora. Se numa semana fica aquém do plano, não abandones — ajusta e continua. A consistência imperfeita bate a perfeição esporádica.

## Quando Quiseres Desistir

Vai acontecer. Provavelmente na semana 6-8 (o "valley of despair"). E depois volta. E volta outra vez.

O que fazer:

- Regressa ao "porquê" — escreve-o e lê quando o motivation cai
- Muda de projecto temporariamente — a variedade do roadmap é intencional
- Fala com a comunidade — não estás sozinho
- Celebra o que já fizeste — o teu eu de 4 semanas atrás ficaria impressionado

## Red Flags Para Evitar

- Perfeccionismo que paralisa: um projecto imperfeito publicado > projecto perfeito não publicado
- Tutorial hell: estudas, nunca constróis. O ratio é 30% teoria, 70% prática.
- Comparação com outros: o teu único adversário és tu de ontem
- Isolamento: a comunidade acelera o crescimento
