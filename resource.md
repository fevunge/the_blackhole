# ESTRATÉGIAS DE CONTEÚDO 2026

## YouTube — Content Strategy

### Tipos de conteúdo

**1. Weekly Progress (5-10min):** O que construíste, o que aprendeste, o que foi difícil. Autêntico, sem script.

**2. Project Showcase (15-20min):** Demo + arquitectura + decisões. Estrutura: problema → solução → implementação → learnings.

**3. Technical Deep Dive (20-30min):** Explica um conceito com profundidade. Usa diagramas, código ao vivo, exemplos reais.

**4. Coding Time-lapse (5-15min):** Sessão de código acelerada com narração. Mostra o processo de pensar, não só o resultado.

### Setup Budget $0

- **Câmara:** Webcam ou smartphone (qualidade suficiente)
- **Microfone:** Mic do laptop numa sala com pouco eco (coloca cobertores)
- **Screen Recording:** OBS Studio (gratuito)
- **Edição:** DaVinci Resolve free (profissional) ou Kdenlive (open-source)
- **Thumbnails:** Canva gratuito

### Growth Tips

- **Shorts/Reels:** Clips de 60s com tips técnicos — distribuição diferente
- **Chapters:** Timestamps no YouTube = melhor retenção e SEO
- **Community Tab:** Polls, updates, previews — mantém audiência engajada
- Consistência > qualidade nos primeiros 3 meses

## Blog — Writing Strategy

### Pilares de conteúdo

1. **"How I Built X"** — processo, decisões, código, learnings
2. **"X vs Y in 2026"** — comparações actualizadas com benchmarks reais
3. **"Understanding X Under the Hood"** — como funciona por dentro
4. **"Mistakes I Made"** — os erros ensinam mais que os sucessos
5. **"Roadmap/Guide to X"** — conteúdo evergreen com SEO forte

### Processo de escrita eficiente

```
1. Outline (15min) — estrutura antes de escrever
2. First draft (1-2h) — escreve sem filtrar, vai à frente
3. Revision (30min) — clareza, fluxo, remove redundâncias
4. Polish (30min) — código correcto, imagens, SEO
5. Publish + Promote (15min) — DEV.to, LinkedIn, Twitter
```

### SEO básico que funciona

- Título: inclui o keyword principal + promessa clara
- H2/H3: subtítulos com keywords secundárias
- Primeiro parágrafo: resume o artigo inteiro
- Links internos: conecta os teus artigos
- Cross-post: DEV.to → Hashnode (alcance duplo, sem penalização SEO)

## LinkedIn — Content Strategy

### Fórmula de posts que performam

**Learning Update:**

```
Aprendi [X específico] hoje.

[Porque é importante]
[Como funciona — 2-3 linhas]
[Onde apliquei]

O que achas? Já usaste isto em produção?
```

**Project Launch:**

```
🚀 Acabei de publicar [Nome do Projecto]

[O que faz em 1 linha]
[Stack: X, Y, Z]
[Desafio técnico mais interessante]

GitHub: [link] | Demo: [link]

[Screenshot ou GIF]
```

**Technical Insight:**

```
💡 [Insight técnico não óbvio]

[Explica o porquê — 3-4 linhas]
[Exemplo concreto]
[Consequência prática]

Concordas?
```

### Engagement que cria relações reais

- Comenta com substância (não "Great post!") — adiciona contexto ou pergunta
- Responde a TODOS os comentários nos teus posts
- Partilha posts de outros com a tua perspectiva adicionada
- Conecta-te com pessoas com mensagem personalizada — menciona algo específico do perfil delas
