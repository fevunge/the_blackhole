# Open-Source Contributions
#week 

## Objectivo

Contribuir com substância para projectos open-source reais — não apenas typos no README.

## Estratégia

1. **Selecciona 3-5 projectos** (alinha com as tecnologias do roadmap)
2. **Estuda o codebase** (1-2 dias por projecto)
3. **Começa por issues marcadas** `good first issue` ou `help wanted`
4. **Escala para features ou bugs reais**

### Projetos por linguagem (2026-relevant)

| Linguagem      | Projectos                                                           |
| -------------- | ------------------------------------------------------------------- |
| **Go**         | Kubernetes, Prometheus, Traefik, pgx (PostgreSQL driver), ent (ORM) |
| **Rust**       | Tokio, axum, Qdrant, uv (package manager), ruff                     |
| **Python**     | FastAPI, Polars, Pydantic, httpx, Ollama Python SDK                 |
| **TypeScript** | Hono, Drizzle ORM, tRPC, Zod, Biome                                 |
| **C++**        | LLVM/Clang, OpenCV, Godot Engine, wgpu-native                       |

### Tipos de contribuição (por ordem de impacto)

1. Bug fix com test (mais impacto, mais difícil)
2. Feature implementation (alinhada com roadmap do projecto)
3. Performance optimization com benchmark
4. Documentation + exemplos funcionais
5. Test coverage para código não testado
